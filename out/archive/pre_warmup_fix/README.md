# 무효 처리된 초기 평가 결과

이 디렉터리의 CSV와 그림은 에이전트와 기준선의 평가 시작일이 달랐던 초기 실행에서 생성됐습니다.

에이전트는 관측창을 만들기 위해 테스트 연도의 첫 구간을 건너뛰었고, Buy & Hold는 연초부터 평가되었습니다. 이 차이가 window 값과 전략별 성과 비교에 영향을 줄 수 있어 해당 결과 전체를 최종 근거에서 제외했습니다.

현재 구현은 직전 거래일을 워밍업으로 붙이고 모든 전략의 평가 시작일과 길이를 검사합니다. 발견 과정과 재실험 원칙은 루트의 `decisions.md`에 기록했습니다.
