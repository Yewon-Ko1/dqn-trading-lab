# out 디렉터리 안내

실험 입력과 결과를 저장합니다. 파일 이름만으로 유효성을 오해하지 않도록 상태를 아래처럼 구분합니다.

## 현재 검증 자료

- `tuning.csv`: 설정·검증 폴드·시드별 원시 결과. 자동 체인 실행 중에는 계속 추가됩니다.
- `auto_chain.md`: 단계별 실행·재사용·판정 기록. 최종 설정 확정 전에는 중간 기록입니다.
- `kospi.csv`, `sp500.csv`, `005930_flow.csv`: 확장 피처 생성을 위한 입력 자료입니다.

## 보관 자료

- `archive/pre_warmup_fix/`: 평가 시작일 정렬 오류를 수정하기 전에 만든 결과입니다. 오류 분석의 추적성을 위해 보관하지만 논문·포트폴리오의 성능 근거로 사용하지 않습니다.

## 로컬 생성 파일

원본 OHLCV, 피처 테이블, 체크포인트처럼 다시 만들 수 있거나 용량이 큰 파일은 기본적으로 Git에서 제외합니다. 최종 설정이 동결되면 평가 결과표와 대표 그림만 선별해 추가합니다.
