# 주차별 진행 기록

각 문서는 그 주에 새로 만든 범위를 중심으로 정리했습니다. 최신 상태와 실험 수치는 루트 [`README.md`](../README.md)와 [`decisions.md`](../decisions.md)를 기준으로 합니다.

| 주차 | 기간 | 새로 만든 범위 | 기록 |
|---|---|---|---|
| 1주차 | 08-28 ~ 09-02 | 데이터·피처·시간 분할·기준선 | [`week1.md`](week1.md) |
| 2주차 | 09-03 ~ 09-09 | 매매 환경·DQN·첫 모델 실험·정책 연동 | [`week2.md`](week2.md) |
| 3주차 | 09-10 ~ 09-16 | 검증 프로토콜·오류 수정·피처 및 거래 제약 실험 | [`week3.md`](week3.md) |
| 4주차 | 09-17 ~ 진행 중 | 자동 튜닝·설정 동결·최종 평가 준비 | [`week4.md`](week4.md) |

1주차의 결과물은 2주차 모델 실험의 입력으로 재사용했습니다. 따라서 2주차의 walk-forward 실험은 분할·기준선을 다시 만든 작업이 아니라, 완성된 검증 모듈에 처음으로 DQN을 연결한 작업입니다.
