# Week 4 회고 (2026-09-17 ~ 진행 중) — 설정 동결과 최종 평가

> 학습 흐름: 데이터·평가 기준 → 환경·에이전트 구현 → 원리 정리와 검증 설계 → **설정 동결과 최종 평가**

앞 주에 정한 규칙대로 남은 설계 항목을 판정하고, 설정을 동결한 뒤 그동안 사용하지 않은 평가 구간 결과를 1회 산출하는 주간입니다. 최신 진행 상태는 루트 [`README.md`](../README.md), 실험 결정은 [`decisions.md`](../decisions.md)를 기준으로 합니다.

## 이번 주 목표

- 설정을 확정하고, 평가 구간 결과를 결과와 무관하게 그대로 보고한다.

## 진행 중인 작업

- 자동 튜닝 체인 실행 — 학습 구간 길이, 보상 패널티, 국면 조건부 피처, 은닉 크기, 학습률, 할인율, 에피소드 수를 검증 폴드 3개 × 시드 20개로 순차 판정
- 단계별 판정은 [`out/auto_chain.md`](../out/auto_chain.md)에, 전체 실행 기록은 [`out/tuning.csv`](../out/tuning.csv)에 축적
- 저장소 문서 정비 — 프로젝트 목적과 검증 설계를 기준으로 [`README.md`](../README.md)와 학습 메모를 다시 작성하고, 평가 정합 오류 수정 이전 결과를 별도 경로로 분리
- 주간 기록을 학습 순서에 맞춰 정리

## 현재 데이터 기준으로 확인한 것

- 학습 구간 5년이 3년 대비 평균 초과수익률을 3.1%p 개선하고 3개 폴드 중 2개에서 우세해 채택 조건을 간신히 충족했습니다. 근거 폭이 좁아 학습 데이터 구성 민감도로 함께 기록했습니다.
- 보상에 매매 패널티를 주면 거래 횟수는 줄지만 초과수익률 변경 조건은 충족하지 못했습니다. 현재 후보 안에서는 최소 보유기간 제약을 학습 신호로 대체하지 못했습니다.
- 장기 추세 피처를 항상 주거나 고변동성 국면에만 주는 방식 모두 작은 피처 세트를 넘지 못했습니다. 국면 조건부 입력은 이번 구성에서 채택하지 않았습니다.
- 은닉 크기 이후 단계는 현재 자동 체인이 재실행 중이므로 완료 후 결과를 확정합니다.
- 수집 시점에 따라 과거 구간 값이 미세하게 달라질 수 있다는 점을 확인했습니다. 원본 소스가 최근 일정 기간만 제공해 보충 구간의 이음매가 이동하기 때문이며, 재실행 시 이전 결과를 재사용하지 못하는 원인이 되었습니다.

## 남은 작업

- 체인 완료 후 설정 동결, 2021~2025년 및 2026년 부분 연도에 대한 최종 평가 1회 실행
- 거래 제약의 효과가 평가 구간에서도 재현되는지 확인하는 절제 실험
- 최종 평가에 사용할 데이터 파일 동결과 기록
- 결과 표와 그림 정리, 논문 원고 작성
- 평가 구간 결과가 기대와 다르더라도 설정을 다시 고르지 않는다는 원칙 유지

## 이번 범위에서 제외한 것

- 다종목 일반화 — 종목 선정 기준은 미리 정해 두었고 실행은 후속 과제로 둡니다.
- 보상 설계 확장과 시장 국면별 모델 전환 구조 — 관찰된 상충을 설명하는 후보로 기록만 남겼습니다.
