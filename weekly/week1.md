# Week 1 회고 (2026-08-28 ~ 2026-09-02) — 데이터와 평가 기준 만들기

> 학습 흐름: **데이터·평가 기준** → 환경·에이전트 구현 → 원리 정리와 검증 설계 → 설정 동결과 최종 평가

모델을 만들기 전에 데이터를 신뢰할 수 있게 다듬고, 무엇과 비교할지부터 정한 주간입니다. 최신 진행 상태는 루트 [`README.md`](../README.md), 실험 결정은 [`decisions.md`](../decisions.md)를 기준으로 합니다.

## 이번 주 목표

- 성능을 내기 전에 "무엇을 어떻게 평가할 것인가"를 먼저 고정한다.

## 완료한 작업

- 저장소 구조와 CI, 이슈·PR 템플릿 구성
- 삼성전자 일봉 수집과 조정주가·액면분할 특성 확인
- 기본 피처 8종 구현과 룩어헤드 검사
- 시간 순 분할, walk-forward fold, 학습 구간 기준 정규화 구현
- 기준선 4종(Buy & Hold, MA20/60 교차, 현금 100%, 고정 노출 50%)과 누적수익률·변동성·Sharpe·Sortino·MDD 구현
- 2024년 기준선 비교를 통해 long/cash 전략의 하락장 한계 확인

## 배운 점

- MDD는 누적 최고점 대비 낙폭으로 계산한다.
- 시간 순 데이터에서는 무작위 셔플보다 학습 이후 구간을 평가하는 방식이 필요하다.
- 데이터 누수와 과적합은 원인과 해결 방법이 다르다.
- 하락장에서는 현금 보유가 강한 기준선이 된다. 수익을 내는 것과 손실을 피하는 것은 다른 목표다.
